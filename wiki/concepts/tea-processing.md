# 一片葉子怎麼變成茶：製茶流程

## 一句話說明
同樣的茶葉，**有沒有萎凋與攪拌、氧化多久、最後有沒有烘焙**，決定它變成哪一種茶。

## 「發酵」到底是什麼
- 製茶時說的「發酵」，主要是葉片細胞內的**酵素**（關鍵是多酚氧化酶）造成的反應，也就是氧化。（來源：[[sources/tbrs-taiwan-aged-tea-1]]）
- 茶葉貯存期間發生的緩慢氧化，則沒有酵素參與，稱為「自動氧化」。（來源：[[sources/tbrs-taiwan-aged-tea-1]]）
- 紅茶製作時，揉捻劇烈破壞葉片細胞，讓茶多酚與氧化酵素反應，最後葉底完全變紅。（來源：[[sources/tbrs-taiwan-specialty-teas]]）

## 常見步驟
| 步驟 | 簡述 | 來源 |
|---|---|---|
| 萎凋 | 日光或室內攤放茶菁，讓葉子失水變軟 | [[sources/tbrs-taiwan-specialty-teas]]（步驟名稱） |
| 攪拌 | 搭配萎凋進行，用來調控氧化程度 | [[sources/tbrs-taiwan-specialty-teas]] |
| 殺菁 | 以高溫（炒或蒸）**破壞氧化酵素，讓氧化停下來** | [[sources/bestea-six-tea-classes]]；步驟名稱見 [[sources/tbrs-taiwan-specialty-teas]] |
| 做青 | 烏龍專屬：反覆搖菁與靜置，讓葉緣氧化（綠葉鑲紅邊） | [[sources/bestea-six-tea-classes]] |
| 悶黃 | 黃茶專屬：殺菁後堆疊覆蓋，濕熱中緩慢轉化 | [[sources/bestea-six-tea-classes]] |
| 揉捻／團揉 | 揉成條形，或用布巾團揉成球形 | [[sources/tbrs-taiwan-specialty-teas]] |
| 乾燥 | 去除水分 | [[sources/tbrs-taiwan-specialty-teas]] |
| 烘焙 | 焙火，產生焙香 | [[sources/tbrs-taiwan-specialty-teas]] |

> 殺菁原理來自商業網站（BESTEA），confidence medium；萎凋的作用原理仍待補。

## 各茶的製程比較
| 茶 | 製程 | 來源 |
|---|---|---|
| 綠茶（碧螺春） | 茶菁 → 殺菁 → 揉捻 → 初乾 → 解塊 → 乾燥（**不經萎凋、攪拌**） | [[sources/tbrs-taiwan-specialty-teas]] |
| 文山包種 | 茶菁 → 日光萎凋 → 室內萎凋及攪拌 → 殺菁 → 揉捻 → 解塊 → 初乾 → 乾燥 | [[sources/tbrs-taiwan-specialty-teas]] |
| 高山烏龍 | 日光萎凋 → 室內萎凋及攪拌 → 殺菁 → 團揉 → 乾燥 | [[sources/tbrs-taiwan-specialty-teas]] |
| 凍頂烏龍 | 同上，另加初乾與**烘焙** | [[sources/tbrs-taiwan-specialty-teas]] |
| 鐵觀音 | 加強攪拌提高氧化程度，成茶再**反覆烘焙** | [[sources/tbrs-taiwan-specialty-teas]] |
| 東方美人 | 重萎凋、重攪拌；炒菁後用濕布巾悶置回潤再揉捻 | [[sources/tbrs-taiwan-specialty-teas]] |
| 紅茶 | 長時間室內萎凋 → 揉捻 → 補足氧化 | [[sources/tbrs-taiwan-specialty-teas]] |

## 給新手的記法
綠茶「直接殺菁」→ 包種、烏龍「先萎凋攪拌再殺菁」→ 紅茶「氧化到底」；想要焙香就「最後再烘焙」。
