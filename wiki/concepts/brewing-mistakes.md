# 泡茶常見錯誤

> 簡報用途：區塊 E「迷思與錯誤」。

| 錯誤 | 會怎樣 | 備註 |
|---|---|---|
| 用滾水泡綠茶 | 鮮爽甘甜消失，只剩苦澀 | |
| 沒有溫壺 | 冷壺降低水溫，香氣釋放不完整 | |
| 浸泡太久（例如馬克杯沒撈出茶葉） | 後段變苦澀 | |
| 沒倒乾淨底湯 | 下一泡一開始就苦 | |
| 自來水直接煮 | 原文稱氯氣與礦物質破壞茶味 | 🔍待查證 |
| 茶葉放太少 | 水味壓過茶味 | |
| 同一份茶葉泡超過 8 泡 | 內含物耗盡，只剩水味 | 次數因茶而異，待交叉比對 |
