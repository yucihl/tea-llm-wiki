# 凍頂烏龍茶

| 項目 | 內容 |
|---|---|
| 風味輪分類 | 焙香型球形烏龍茶 |
| 氧化程度 | 中度（原文：中度發酵）⚠️ 另有 15–20% 的說法，見 [[concepts/oolong-vs-baozhong]] |
| 主要產地 | 原產南投鹿谷，技術已擴展到竹山、名間等茶區 |
| 主要品種 | 青心烏龍（來源：[[sources/tbrs-central-south-tea-regions]]） |
| 外觀 | 緊結球形，墨綠油潤 |
| 風味 | 水色金黃明亮，香氣濃郁帶**焙火香**，滋味醇厚、喉韻佳 |

（以上來源：[[sources/tbrs-taiwan-specialty-teas]]，另註明者除外）

## 演變
- 1970 年代中期鹿谷優良茶比賽規定半球形外觀，以「凍頂烏龍茶」行銷後轟動市場。（來源：[[sources/tbrs-dongding-aged-tea-2]]）
- 之後評審轉而要求金黃水色與清香，清香型製法再影響到高山茶。（來源：[[sources/tbrs-dongding-aged-tea-2]]）
- 鹿谷的凍頂仍標榜較高的氧化程度與深焙火。（來源：[[sources/tbrs-central-south-tea-regions]]）

## 冷知識
- 依製法，凍頂其實應歸為「半球形包種茶」。見 [[concepts/oolong-vs-baozhong]]。

> 簡報用途：區塊 D 與鐵觀音合併一頁（焙香型）。
