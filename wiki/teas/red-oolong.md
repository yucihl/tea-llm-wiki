# 紅烏龍茶

| 項目 | 內容 |
|---|---|
| 風味輪分類 | 焙香型球形烏龍茶 |
| 氧化程度 | 烏龍茶類中最高，著重烘焙 |
| 主要產地 | 台東鹿野 |
| 主要品種 | — |
| 外觀 | 半球形，暗紅帶光澤 |
| 風味 | 水色橙紅像紅茶，**滋味卻是烏龍**；熟果香、醇厚耐泡 |

（以上來源：[[sources/tbrs-taiwan-specialty-teas]]，另註明者除外）

## 重點
- 2008 年茶改場東部分場為鹿野茶區創製，結合烏龍茶與紅茶的加工特點。（來源：[[sources/tbrs-taiwan-specialty-teas]]）
- 利用夏秋茶芽（做包種茶易苦澀）來製作，熱泡、冷泡都適合。（來源：[[sources/tbrs-taiwan-specialty-teas]]）

> 簡報用途：區塊 D 與日月潭紅茶合併一頁（「像紅茶的烏龍」對比「真正的紅茶」）。
