# 文山包種茶

| 項目 | 內容 |
|---|---|
| 風味輪分類 | 清香型條形包種茶 |
| 氧化程度 | 輕度（原文：輕度發酵） |
| 主要產地 | 新北市坪林、石碇、深坑、平溪、汐止、新店、三峽；台北市南港、木柵 |
| 主要品種 | 青心烏龍、臺茶 12 號 |
| 外觀 | 芽葉自然捲曲、條索緊結，墨綠帶油光 |
| 風味 | 水色蜜黃碧綠，特別注重**花香**，滋味圓滑甘醇 |

（以上來源：[[sources/tbrs-taiwan-specialty-teas]]，另註明者除外）

## 名字的由來
- 早年將茶葉用四方形毛邊紙包起來販售，成為「包種」名稱的通俗由來；產區日治時期多屬台北州文山郡。（來源：[[sources/tbrs-taiwan-specialty-teas]]）

## 給新手的重點
- 台灣少數仍維持**條形**的部分發酵茶，其他茶區多做成球形。（來源：[[sources/tbrs-dongding-aged-tea-2]]）
