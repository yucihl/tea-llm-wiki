# 鐵觀音茶

| 項目 | 內容 |
|---|---|
| 風味輪分類 | 焙香型球形烏龍茶 |
| 氧化程度 | 中度，重度烘焙（原文：中度發酵重度烘焙） |
| 主要產地 | 台北市木柵、新北市石門 |
| 主要品種 | 鐵觀音品種製成者稱「正欉鐵觀音」，為上品 |
| 外觀 | 球形 |
| 風味 | 水色琥珀略紅，味濃醇厚，微澀帶甘，有弱果酸味 |

（以上來源：[[sources/tbrs-taiwan-specialty-teas]]，另註明者除外）

## 和凍頂的差別（給新手）
- 兩者都是焙香型；鐵觀音透過加強攪拌提高氧化程度，再**反覆烘焙**，焙火比凍頂更重。（來源：[[sources/tbrs-taiwan-specialty-teas]]）
- 清光緒年間由安溪引進茶苗種在木柵。（來源：[[sources/tbrs-taiwan-specialty-teas]]）

> 簡報用途：區塊 D 與凍頂合併一頁。
