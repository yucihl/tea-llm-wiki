# 碧螺春綠茶（台灣綠茶代表）

| 項目 | 內容 |
|---|---|
| 風味輪分類 | 臺灣綠茶 |
| 氧化程度 | 不氧化（不發酵茶） |
| 主要產地 | 新北市三峽（台灣唯一僅剩的專業炒菁綠茶產區） |
| 主要品種 | 青心柑仔、青心烏龍 |
| 外觀 | 碧綠、白毫多，細緊捲曲似螺旋 |
| 風味 | 清香鮮雅，茶湯碧綠清澈、鮮活爽口 |

（以上來源：[[sources/tbrs-taiwan-specialty-teas]]，另註明者除外）

## 給新手的重點
- 綠茶製程**不經萎凋、攪拌**，直接殺菁。見 [[concepts/tea-processing]]。
- 清明前採一心二葉的嫩芽品質最佳。（來源：[[sources/tbrs-taiwan-specialty-teas]]）

> 簡報用途：放在區塊 C「綠茶」頁當台灣代表，不放區塊 D（使用者決定）。
