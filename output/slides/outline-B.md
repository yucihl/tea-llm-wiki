# 區塊 B：一片葉子怎麼變成茶

## B1 | 一片葉子的旅程
layout: steps
wiki: concepts/tea-processing, glossary
lead: 不是每種茶都會走完全部步驟——少走哪一步、多走哪一步，就變成不同的茶
steps:
- 萎凋 | 攤放茶菁，讓葉子失水變軟
- 做青 | 烏龍專屬：反覆搖菁與靜置，讓葉緣氧化
- 殺菁 | 用高溫（炒或蒸）讓氧化停下來
- 揉捻 | 揉成條形，或用布巾團揉成球形
- 乾燥 | 去除水分
- 烘焙 | 選擇性：焙火，產生焙香

## B2 | 製茶的「發酵」，其實是「氧化」
layout: statement
wiki: concepts/tea-processing, glossary, comparisons/six-tea-types
big: 製茶說的「發酵」，主要是葉片裡的酵素在作用
bullets:
- 關鍵的酵素叫「多酚氧化酶」，讓茶多酚產生變化
- 所以這份簡報寫成「氧化程度（俗稱發酵）」
- 茶葉存放時沒有酵素參與的緩慢變化，叫「自動氧化」
- 只有黑茶的「後發酵」，才真的有微生物參與

## B3 | 殺菁：讓氧化停下來的開關
layout: compare
wiki: concepts/tea-processing, comparisons/six-tea-types
lead: 什麼時候殺菁，決定了茶葉氧化到哪裡
left: 綠茶：一採下就殺菁
- 高溫破壞氧化酵素
- 茶葉幾乎不氧化
- 所以湯色淡黃綠、保留鮮爽
right: 包種、烏龍：先萎凋、做青，再殺菁
- 先讓葉子氧化一部分
- 到想要的程度再殺菁「定住」
- 做青讓葉緣氧化，形成「綠葉鑲紅邊」
note: 紅茶則是揉捻破壞葉片細胞，讓氧化一路進行到底

## B4 | 不同的茶，不同的路線
layout: table
wiki: concepts/tea-processing
lead: 同樣從茶菁出發，步驟的差異造就了不同的茶
table:
| 茶 | 製程重點 |
|---|---|
| 綠茶（碧螺春） | 不萎凋、不攪拌，直接殺菁 → 揉捻 → 乾燥 |
| 文山包種 | 日光萎凋 → 室內萎凋及攪拌 → 殺菁 → 揉捻 → 乾燥 |
| 高山烏龍 | 萎凋及攪拌 → 殺菁 → 團揉成球形 → 乾燥 |
| 凍頂烏龍 | 同高山烏龍，最後再加上烘焙 |
| 東方美人 | 重萎凋、重攪拌，炒菁後用濕布巾悶置回潤 |
| 紅茶 | 長時間萎凋 → 揉捻 → 補足氧化 |

## B5 | 一句話記住製茶
layout: statement
wiki: concepts/tea-processing
big: 綠茶「直接殺菁」→ 包種、烏龍「先萎凋做青再殺菁」→ 紅茶「氧化到底」
bullets:
- 想要焙香？最後再加一道「烘焙」
- 外觀是條形還是球形，看的是揉捻的方式
